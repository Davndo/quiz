Vegetables Classification using a Deep Convolutional Neural Network (DCNN) · 3rd Session (Processing Images)

The case

VeggieLKa is set to make a significant impact in the agri-tech sector by promoting sustainable agriculture and healthy eating. Their goal is to introduce an innovative system that enhances the classification and sorting of vegetables on a granular level, ultimately improving the efficiency and precision of global vegetable supply chains.

As the latest recruit, you are tasked with spearheading this groundbreaking project. Your mission is to develop a Python-based program utilizing the TensorFlow library to craft a Deep Convolutional Neural Network (DCNN) model. This advanced model will specialize in accurately distinguishing between four primary vegetable classes: Broccoli, Carrot, Cucumber, and Tomato.

Requirements

  1. Load and split datasetAssign the dataset path, populate CLASS_NAMES, load each image as grayscale into an array, shuffle, then split into training / validation / testing (80 / 10 / 10).
  2. Data preprocessingConvert each set to float32, normalize pixel values by dividing by 255, and optionally one-hot encode the target labels.
  3. DCNN architecture — input layerDefine the image dimensions and channel count for the input layer.
  4. DCNN architecture — hidden layersStack convolutional layers, max pooling layers, and a flatten layer to extract and reduce feature map dimensions.
  5. DCNN architecture — output layerTwo dense layers: one ReLU-activated, and a final Softmax layer to classify into one of the four vegetable classes.
  6. Model trainingUse the Adam optimizer, an appropriate loss function, accuracy as the metric, and train for at least 10 epochs.
  7. Prediction & evaluationPredict on the testing set and print both loss and accuracy; evaluate the testing set the same way.
  8. Plot of evaluation metricsPlot training vs. validation loss, and training vs. validation accuracy.

Imports
import os
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from sklearn.model_selection import train_test_split
from tensorflow.keras.utils import load_img, img_to_array, to_categorical
Load data
DATA_PATH = "Dataset"
CLASS_LIST = ["Broccoli", "Carrot", "Cucumber", "Tomato"]
EPOCHS = 10
BATCH_SIZE = 32
images = []
labels = []
Load & preprocess
for i, class_name in enumerate(CLASS_LIST):
  # 0 Broccoli, 1 Carrot, 2 Cucumber, 3 Tomato
  folder_path = os.path.join(DATA_PATH, class_name)

  # NOTE: don't forget os.listdir (common mistake, causes an error if skipped)
  for j, image_name in enumerate(os.listdir(folder_path)):
    image_path = os.path.join(folder_path, image_name)

    # param1 = image path, param2 = target size, param3 = color mode
    image = load_img(image_path, target_size=(64, 64), color_mode="grayscale")
    image = img_to_array(image)
    image = image / 255.0  # normalize [0,255] -> [0,1]

    images.append(image)
    labels.append(i)

    # only take 100 images per class, in case the device can't handle more
    if j > 98:
      break
Train / validation / test split
x = np.array(images, dtype=np.float32)
y = to_categorical(labels, num_classes=len(CLASS_LIST))

# the brief says 80 | 10 | 10 — since train_test_split only splits in two,
# do it twice: first 80/20, then split that 20 in half again for 10/10
x_train, x_temp, y_train, y_temp = train_test_split(x, y, random_state=9, test_size=0.2)
x_test, x_val, y_test, y_val = train_test_split(x_temp, y_temp, random_state=10, train_size=0.5)
Model build
model = tf.keras.Sequential([
    # Conv2D params: filters, kernel size, stride, padding, input shape, activation
    tf.keras.layers.Conv2D(16, kernel_size=(3,3), strides=(1,1), padding="same",
                            input_shape=(64, 64, 1), activation="relu"),
    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Conv2D(32, kernel_size=(3,3), strides=(1,1), padding="same"),
    tf.keras.layers.Conv2D(32, kernel_size=(3,3), strides=(1,1), padding="same"),
    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(32, activation="relu"),
    tf.keras.layers.Dense(len(CLASS_LIST), activation="softmax")
])

model.compile(
    optimizer="adam",
    loss="categorical_crossentropy",  # multi-class, so categorical_crossentropy
    metrics=["accuracy"]
)
Training run (actual output)
history = model.fit(
    x_train, y_train,
    validation_data=(x_val, y_val),
    epochs=EPOCHS,
    batch_size=BATCH_SIZE
)
